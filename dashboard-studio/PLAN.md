# Five complete dashboard alternatives

The user approved expanding the five existing concepts into complete frontend experiences. All alternatives use actual persisted project context. Live inference, ingestion, and contractual decisions remain disconnected.

## Delivery

- Read existing company source packets and recorded analyses without modifying their databases.
- Generate a traceable common snapshot with public, reconstructed, generated and synthetic provenance retained.
- Build five independent full-page experiences: Constellation, Investigation board, Reading desk, Storyline, and Signal matrix.
- Reuse one small browser runtime for company selection, source/assumption inspection, search and exports; retain separate visual structures.
- Make all displayed controls functional locally. Do not simulate inference or claim proposed terms are operative.
- Provide a local index and static-server launch instructions. No dependencies or production server changes.
- Verify company switching, searches, source inspection, selected-record behavior, five desktop layouts and narrow layouts using the installed Playwright runtime.

## Files and ownership

- `build_data.py`, `dataset.js`, `DATA.md`: read-only data extraction and provenance.
- `shared.js`, `shared.css`: shared browser utilities and inspection dialogs.
- `constellation.*`: spatial relationship explorer.
- `board.*`, `storyline.*`: investigation and history experiences.
- `desk.*`, `matrix.*`: source reading and relationship comparison.
- `index.html`, `README.md`, `verify.cjs`: entry point, operation, meaningful browser verification.

## Acceptance

Every dashboard uses company-specific actual records, shows source text and model provenance, supports search and inspection, and displays pending/unknown/unassessed states faithfully. No existing borrower or benchmark state is modified. Public-company datasets are historical snapshots, not current financial advice.
